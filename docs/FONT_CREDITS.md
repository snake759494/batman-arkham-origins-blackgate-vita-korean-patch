# 글꼴 출처

원본 일본어 글꼴이 모두 고딕 계열이라 굵기만 맞춰 나눔스퀘어네오를 썼습니다. 가장 작은 글꼴도 글자 칸이 15px 이상이라 비트맵 글꼴(갈무리)은 쓰지 않았습니다.

| 게임 글꼴 | 용도 | 한글 글꼴 |
| --- | --- | --- |
| `bm_game` | 본문·설명문·배트컴퓨터 | 나눔스퀘어네오 Rg (`NanumSquareNeo-bRg.ttf`) |
| `linefeed` | 자막·안내 | 나눔스퀘어네오 Rg (`NanumSquareNeo-bRg.ttf`) |
| `chainprinter_small` | 작은 메뉴·버튼 안내 | 나눔스퀘어네오 Rg (`NanumSquareNeo-bRg.ttf`) |
| `chainprinter` | 메뉴 | 나눔스퀘어네오 Bd (`NanumSquareNeo-cBd.ttf`) |
| `voxbold` | 강조·제목 | 나눔스퀘어네오 Eb (`NanumSquareNeo-dEb.ttf`) |
| `bm_header` | 큰 제목 | 나눔스퀘어네오 Eb (`NanumSquareNeo-dEb.ttf`) |

- 나눔스퀘어네오: © NAVER Corp. 네이버 나눔글꼴 라이선스에 따라 무료로 사용합니다(https://hangeul.naver.com/font).

글꼴 파일은 저장소에 포함하지 않습니다. 게임에 들어가는 것은 번역에 쓰인 848자를 그린 텍스처뿐입니다. 재빌드하려면 위 글꼴을 받아 `fonts/`에 두세요.
